Sales Performance Dashboard 📊

I created an interactive Sales Performance Dashboard using Microsoft Excel. 
The project analyzes sales data based on Region, Product, and Salesperson using Pivot Tables and Pivot Charts. 
I also added KPIs for Total Sales and Total Units Sold, along with Region and Product Slicers to make the dashboard interactive and easy to filter.
